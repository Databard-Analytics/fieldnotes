# Briefs

Store daily briefs here as markdown files.

Suggested filename format:

- `YYYY-MM-DD-short-title.md`

Example:

- `2026-04-25-ai-data-strategy-signals.md`

Suggested frontmatter:

```md
---
title: AI and Data Strategy Signals
date: 2026-04-25
summary: A short summary of the brief.
tags:
  - ai-strategy
  - data-strategy
  - brief
theme: ai-strategy
draft: false
---
```
